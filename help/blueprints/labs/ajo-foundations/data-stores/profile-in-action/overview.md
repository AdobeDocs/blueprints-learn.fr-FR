## Présentation de l’atelier

Dans cette vidéo, vous découvrirez comment cet atelier simule une visite d’une page web d’Edge Network dans Adobe Experience Platform, et comment vous validerez le profil obtenu, la qualification du segment et l’événement de lac de données.

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## Objectifs d’apprentissage

Dans cet exercice, nous allons simuler une visite d’une page web d’une source Edge vers Adobe Experience Platform. Avec quoi devriez-vous partir après avoir pris ce labo ?

- Création et configuration d’un flux de données dans Adobe Experience Platform
- Envoyer un événement web de test à Edge Network à l’aide de Postman
- Valider la création de profil et la qualification du segment dans le profil en temps réel
- Vérifiez que le profil existe sur Edge mais pas encore dans le jeu de données d’instantanés de profil.
- Vérifiez que l’événement a été stocké dans le lac de données.
