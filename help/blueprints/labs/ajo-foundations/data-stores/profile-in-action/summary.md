# Résumé

Dans cet atelier, vous avez configuré un flux de données et envoyé un événement web simulé à Edge Network à l’aide de Postman pour observer le flux de données dans Adobe Experience Platform.

Vous avez validé que l’événement a été traité par plusieurs services de plateforme en confirmant qu’un profil a été créé et qualifié pour un segment dans le profil en temps réel. Vous avez également vérifié que le profil existait au niveau d’Edge, confirmé que l’événement était stocké dans le lac de données et observé que le profil n’était pas encore apparu dans le jeu de données d’instantanés de profil en raison de son processus de mise à jour par lots planifié.

Grâce à ces étapes, vous avez démontré comment les événements se déplacent dans les couches Edge, Profil en temps réel et Lac de données de Adobe Experience Platform.
