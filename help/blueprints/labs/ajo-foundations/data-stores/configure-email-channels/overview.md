# Configuration des canaux e-mail

>[!CAUTION]
>
>Ce Lab nécessite un sous-domaine délégué à Adobe dans votre sandbox. Si vous faites votre propre rythme et n’en avez pas encore configuré une, reportez-vous à la section [Configuration](../../setup.md) avant de continuer ; cette étape peut prendre jusqu’à 3 heures.

## Présentation de l’atelier

Dans cette vidéo, vous allez découvrir les deux configurations de canal e-mail utilisées dans cet atelier : l’une utilisant un attribut de profil AEP et l’autre utilisant un attribut de schéma relationnel comme adresse d’exécution.

>[!VIDEO](https://video.tv.adobe.com/v/3486540/)

## Objectifs d’apprentissage

- Configuration du canal e-mail à l’aide de l’attribut de profil AEP pour les campagnes orchestrées
- Configuration du canal e-mail à l’aide de l’attribut de schéma relationnel pour les campagnes orchestrées

Les canaux e-mail sont utilisés dans l’atelier suivant pour aider à comprendre les nuances de l’utilisation d’une configuration par rapport à l’autre.
