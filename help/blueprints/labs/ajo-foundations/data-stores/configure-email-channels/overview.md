# Configuration des canaux e-mail

## Présentation de l’atelier

Dans cette vidéo, vous apprendrez à créer les deux configurations de canal e-mail utilisées dans cet atelier : l’une utilisant un attribut de profil AEP et l’autre utilisant un attribut de schéma relationnel comme adresse d’exécution.

>[!VIDEO](https://video.tv.adobe.com/v/3486540/)

## Objectifs d’apprentissage

- Configuration du canal e-mail à l’aide de l’attribut de profil AEP pour les campagnes orchestrées
- Configuration du canal e-mail à l’aide de l’attribut de schéma relationnel pour les campagnes orchestrées

Les canaux e-mail seront utilisés dans le prochain atelier pour aider à comprendre les nuances de l’utilisation d’une configuration par rapport à l’autre.
