# En attente de statut actif

>[!CAUTION]
>
>Avant de pouvoir poursuivre vos recherches dans les prochains laboratoires, vous devez vous assurer que vos configurations de canal e-mail s’affichent toutes deux comme **Actives**

![Deux configurations de canal e-mail affichant toutes deux le statut Actif](assets/waiting-for-active-status-email-channel-configurations-active.png "Les configurations de canal e-mail affichant le statut Actif")

>[!TIP]
>
> 🚀 Une fois que le statut de configuration du canal e-mail est **Actif** vous pouvez continuer 😅

Vous savez maintenant comment créer une configuration du canal e-mail pour utiliser l’attribut de schéma relationnel pour les campagnes orchestrées.
