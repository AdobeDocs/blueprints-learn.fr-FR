# Identifier

## Objectifs d’apprentissage

L’étape **Identifier** de la méthodologie LID est divisée en deux parties distinctes :

1. Partie 1 - Types de tables restants -> identifier les tables restantes sans libellé et étiqueter le type de dénormalisation
1. Partie 2 - Champs clés -> identifier les champs clés des entités principales et annexes



Il vous apprendra à identifier les éléments suivants dans un modèle relationnel dont vous aurez besoin pour concevoir le profil client en temps réel :

- Tables Bridge (tables qui gèrent les relations multiples-à-multiples)
- Tableaux qui nécessiteront une dénormalisation
- Identités de Principal dans le profil client en temps réel
- Identités basées sur des personnes au sein des classes d’entités principales qui peuvent être utilisées pour identifier une personne de manière unique
- Identifiants de relation entre les tables Profil individuel/Événement d’expérience et les tables de recherche associées
- Champs obligatoires pour les schémas Événement d&#39;expérience
- Champs recommandés pour les schémas de profil individuel et de recherche
