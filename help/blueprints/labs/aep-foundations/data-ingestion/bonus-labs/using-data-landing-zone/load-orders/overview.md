# Charger les commandes

## Présentation de l’atelier

Cet atelier présentera les transformations de données complexes et le traitement des données JSON.

## Objectifs d’apprentissage

Quels sont les principaux points à retenir de ce laboratoire ?

- Comprendre l’ingestion par lots de données JSON imbriquées
- Utilisez la copie d’objet comme concept pour simplifier les mappages de champs entre les champs non XDM complexes et XDM.
