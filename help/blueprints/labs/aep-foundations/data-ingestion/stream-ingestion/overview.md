# Ingestion de flux

## Objectifs d’apprentissage

Dans cet exercice, nous allons charger les données du compte client à partir d’une source de diffusion en continu vers le lac de données et le profil Adobe Experience Platform. Avec quoi devriez-vous partir après avoir pris ce labo ?

- Création d’une entrée de diffusion en continu
- Importation du jeu de mappages à partir d’un autre flux de données
- Obtention de l’identifiant du flux de données et de l’identifiant du jeu de données à partir de l’interface utilisateur
- Utilisation de l’API REST pour ingérer un événement

>
>Si vous n’avez pas terminé la création du schéma Comptes clients dans les exercices pratiques précédents, vous pouvez accéder au catalogue de schémas et utiliser à la place **dep: Customer Account**
