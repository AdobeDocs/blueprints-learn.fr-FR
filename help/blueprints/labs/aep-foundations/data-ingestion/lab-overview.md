# Présentation de l’atelier

## Objectifs

L’objectif de ces laboratoires est de vous préparer à relever les défis pratiques de l’ingestion de données. Grâce à ces connaissances, vous serez en mesure de gérer et de guider votre équipe dans les implémentations de données en production. Bien que la théorie soit fascinante, nous allons passer du temps à déboguer les problèmes au fur et à mesure qu&#39;ils se présenteront et à relier ce que nous voyons dans l&#39;outil à celui des concepts plus larges enseignés dans ce bootcamp.



## À quoi s’attendre ?

J&#39;ai besoin que vous vous concentriez. En voici la raison : les données seront la base de toute implémentation que vous effectuerez.

Les problèmes de données ne sont pas faciles. Les données sont désordonnées, incomplètes, éparpillées et difficiles à introduire dans le système là où vous en avez besoin. Ces laboratoires sont conçus pour vous donner un avant-goût de ces scénarios.

Ces prochains laboratoires nécessiteront de l&#39;attention et du dévouement, car vous toucherez les entrailles du système. Il n’est pas prévu que vous absorbiez tous les concepts en une seule fois. Prenez donc le temps de trouver votre chemin dans le laboratoire.



## Plan d&#39;étude en résumé

Puisque vous disposez de schémas sources et que vous avez défini des schémas cibles dans XDM, vous devez connecter les deux schémas par le biais de mappages. Comme ce processus nécessite un mappage champ par champ, vous devrez apprendre certaines techniques qui accélèrent le processus tout en étant conscient de certains pièges courants :

- Présentation des mappages passthrough
- Correction des mappages passthrough générés par l’IA/ML
- Utilisez l’aperçu des données sources pour vérifier les problèmes de qualité des données

Une fois le mappage de schéma configuré, vous devez tester votre travail et déboguer les erreurs et avertissements :

- Planifier une exécution de flux de données
- Marquer un jeu de données pour Profil
- Traiter les erreurs provenant de valeurs manquantes dans les champs obligatoires
- Traiter les erreurs provenant d’erreurs de correspondance de type de données
- Traiter les erreurs d’ingestion de données et récupérer après de tels échecs
- Utilisez de manière itérative des données de test pour générer un jeu de mappages complet.
- Vérifiez et validez les données ingérées avec succès.

Vous apprendrez les concepts ci-dessus avec les scénarios d’ingestion de données relationnelles et non relationnelles.
