# Modélisation des API

## Présentation de l’atelier

L’utilisation des API d’Experience Platform est essentielle pour comprendre comment automatiser et rendre opérationnelles diverses fonctionnalités de la plateforme. La définition de schémas et la compréhension de la manière dont les données sont décrites par ces schémas sont l’une des premières choses qu’un client fera sur Adobe Experience Platform lorsqu’il définira son architecture de données.

Ce Lab vous présentera l’expérience de conception de schéma Adobe Experience Platform en n’utilisant que les API. Vous apprendrez à créer vos propres schémas à l’aide de composants XDM existants, à ajouter vos propres personnalisations dans XDM et à identifier et créer divers descripteurs d’identité à utiliser avec le profil client en temps réel.

## Objectifs d’apprentissage

être en mesure de créer un schéma en utilisant uniquement les API Experience Platform par le biais de divers composants de base XDM tels que :

1. Classes
1. Groupes de champs
1. Descripteurs
   1. Identités (y compris le Principal)
   2. Relation
   3. Référence
