# Conférences

XDM (modèle de données d’expérience) est le cadre normalisé d’Adobe pour organiser les données d’expérience client sur différents systèmes. Il garantit que les données provenant de diverses sources (sites web, applications et CRM, par exemple) sont structurées de manière cohérente, ce qui facilite l’unification, l’analyse et l’activation en temps réel. Cette cohérence est essentielle pour créer des profils clients précis, activer des expériences personnalisées et prendre en charge les informations basées sur l’IA dans Adobe Experience Platform.
