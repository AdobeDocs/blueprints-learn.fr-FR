# Connexion et navigation

## Connexion via l’interface utilisateur

1. Accédez à [&#128279;](https://experience.adobe.com/) dans votre navigateur.
1. Connectez-vous à l’aide d’Adobe ID qui dispose d’un accès développeur à votre sandbox, le même que celui utilisé pour terminer la configuration de [Developer Console](../../sandbox-setup/developer-console-setup.md).
1. Sur l’écran **Sélectionner un compte** choisissez le **Compte d’entreprise ou d’école**.

![Page de connexion Adobe pour accéder à votre page de connexion Adobe ID](assets/login-and-browse-adobe-login-page.png "Adobe")

![Page de saisie du mot de passe Adobe](assets/login-and-browse-adobe-password-page.png "Page du mot de passe Adobe")

![Sélectionnez un écran de compte avec l’option Compte d’entreprise ou d’école](assets/login-and-browse-select-company-or-school-account.png "Connexion à Adobe avec invite de sélection de profil")


## Lancer Experience Platform

Cliquez sur l’icône Experience Platform dans le panneau d’accès rapide pour accéder à votre sandbox de bootcamp

>[!NOTE]
>
>Il se peut que cet écran ne s’affiche pas et que vous soyez lancé directement dans Experience Platform.  Si tel est le cas, ignorez cette étape.

![Panneau d’accès rapide avec l’icône Experience Platform](assets/login-and-browse-quick-access-experience-platform.png "Accès rapide pour Experience Platform")


## Accès aux schémas

1. Cliquez sur l’onglet **Schémas** dans le rail de gauche

![Onglet Schémas dans le volet de navigation du rail de gauche](assets/login-and-browse-schemas-tab-left-rail.png "Accédez aux schémas à l’aide du rail de gauche")

1. Dans le volet de navigation supérieur, vous pouvez parcourir les schémas existants et afficher les groupes de champs et les types de données qui se trouvent actuellement dans le registre XDM.

![Options de navigation principales pour parcourir les schémas, les groupes de champs et les types de données](assets/login-and-browse-browse-schemas-top-nav.png "Navigation dans les schémas")

>[!NOTE]
>
>Vous remarquerez qu’il existe déjà des schémas précréés dans votre sandbox. Il s’agit notamment des schémas qui ont été précréés dans le cadre de ce bootcamp (ils sont précédés du préfixe `dep`), ainsi que des schémas générés par le système pour Adobe Real-Time CDP et Adobe Journey Optimizer.

>[!TIP]
>
>Commencez à créer des schémas !
