# Modélisation de l’interface utilisateur

## Mappage de la source à XDM

Apprenez à traduire ce que vous avez mis sur papier et apprenez à découvrir et à mapper des objets et des champs XDM **standard** plutôt que de créer des objets et des champs **personnalisés**.

Ce que vous repartirez avec :

- Connaissance de l’interface utilisateur de la manière dont les concepts du modèle de données d’expérience apparaissent dans la vie réelle
- Comprendre comment les objets et les champs sont définis dans le contexte des **groupes de champs XDM**
- Comprendre comment utiliser l’interface utilisateur du schéma pour explorer les groupes de champs standard XDM



## Création de XDM via l’interface utilisateur

Commencez directement à créer le schéma Compte client Connection 5G qui utilise le schéma que vous avez créé à l’aide de la méthodologie LID

Ce que vous repartirez avec :

- Compréhension de base de l’interface utilisateur globale de la composition de schémas
- Découvrez comment ajouter des groupes de champs standard XDM à un schéma
- Découvrez comment supprimer les champs inutiles des groupes de champs standard XDM
- Création et utilisation de groupes de champs personnalisés dans un schéma
- Apprenez à enregistrer souvent pendant les 😄 de développement de schéma.
- Comprendre les différences entre les énumérations et les valeurs suggérées



## Configuration pour le profil

Découvrez les étapes requises pour configurer un schéma à utiliser avec le profil client en temps réel, du marquage d&#39;identité à l&#39;établissement de relations pour les schémas de recherche.

Ce que vous repartirez avec :

- Être en mesure de marquer un champ comme identité ou identité principale
- Créer une relation entre deux schémas
- Comprenez la raison pour laquelle **tester** le schéma avant d’activer pour le profil
- Comprenez le **schéma d’union** et visualisez-le en action
