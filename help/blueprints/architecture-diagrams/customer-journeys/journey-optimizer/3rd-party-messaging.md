# Messagerie Tiers

>[!TIP]
>Cette architecture est également documentée sous la forme d’un [modèle de cas d’utilisation](/help/blueprints/use-case-patterns/campaign-management-orchestration/third-party-messaging.md) sous Gestion et orchestration des campagnes.

Montre comment Adobe Journey Optimizer peut être utilisé avec des systèmes de messagerie tiers pour envoyer des communications personnalisées.

<br>

## Architecture

Journey Optimizer d’architecture de référence![&#128279;](images/ajo-third-party-messaging.png){width="1000" zoomable="yes"}

<br>

La topologie indique [!DNL Journey Optimizer] envoyer des payloads transactionnels à un tiers
application de messagerie par le biais d’une action personnalisée ou d’une intégration API REST. Utiliser le modèle de cas d’utilisation de messagerie [tierce](/help/blueprints/use-case-patterns/campaign-management-orchestration/third-party-messaging.md)
pour les conditions préalables, les mécanismes de sécurisation et les conseils d’implémentation.
